# Big Boss in the Lands Between

A comprehensive mashup of **Metal Gear Solid V: The Phantom Pain** and **Elden Ring**, bringing tactical espionage operations to the Lands Between.

## Overview

Experience Elden Ring as **Big Boss**, the legendary soldier from MGSV. This mod integrates the full arsenal, stealth mechanics, and tactical systems from Metal Gear Solid V directly into Elden Ring's combat and exploration.

## Core Features

### 🎯 Full MGSV Weapon Arsenal
- **Mosin Nagant** - Precision sniper rifle
- **Bullhorn Shotgun** - Close-quarters devastation
- **Serval Pistol** - Reliable sidearm
- **Tranquilizer Gun** - Non-lethal approach
- **Hand Cannon** - Heavy pistol impact
- **Riot Gun** - Combat shotgun efficiency
- **AM D-114** - Assault rifle versatility
- **Stun Arm** - Non-lethal crowd control

All weapons maintain **MGSV stat scaling**, bypassing Elden Ring's upgrade system for authentic MGSV gameplay.

### 🕵️ Stealth Detection System
The legendary MGSV detection phases fully integrated:
- **Undetected** - Enemies unaware
- **Evasion** - Enemies suspicious and searching
- **Caution** - Combat imminent
- **Alert** - Full engagement

**Stealth Mechanics:**
- Crouch movement with reduced noise/visibility
- Hide in tall grass to avoid detection
- Sound masking (rain, thunder, machinery)
- Tranquilizer-based non-lethal approach

### 🚁 Helicopter Air Support
Call in tactical air support or fast travel via helicopter:
- **Helicopter Gunfire** - Covering fire during combat (60s cooldown)
- **Airstrike** - Strike marked positions (90s cooldown)
- **Supply Drops** - Request ammunition and supplies (45s cooldown)
- **Helicopter Extraction** - Fast travel to visited locations (replaces Sites of Grace, 30s cooldown)

### 👥 Buddy System
Summon MGSV companions for support:
- **Quiet** - Sniper support, enemy marking, distraction tactics
- **Diamond Dogs** - Enemy detection, pack distraction, resource gathering

### ⚔️ Boss Encounters
All Elden Ring bosses remain challenging, now faced with MGSV mechanics and weapons. Use stealth, reconnaissance, and tactical planning alongside combat skills.

## Installation

**Requirements:**
- Elden Ring (PC)
- ModEngine2
- universal-modder toolkit

**Steps:**
1. Clone this repository
2. Follow ModEngine2 installation guide
3. Load the mashup configuration
4. Launch Elden Ring with ModEngine2
